# Style recipes

Each recipe is a worked starting point for one look: the medium with its numbers, the type, the motion
personality, what each section does, how it is built, and how it goes wrong. Adapt them to the song; never
ship one unchanged. Two recipes can mix only if one is the world and the other an event inside it (a print world
that tears open into film in the bridge).

| Recipe | Feel | Built from | Gen cost |
|---|---|---|---|
| `riso-zine.md` | raw, DIY, punk, indie, hyperpop | code: print layers, halftone, type | none |
| `cut-paper.md` | warm, handmade, nostalgic, folk, storytelling | code: SVG layers, paper texture, shadows | none |
| `ink-night.md` | intimate, sad, slow, confessional | code + canvas: ink bloom, one accent | none |
| `film-collage.md` | memory, archival, cinematic, nostalgic | real footage/photos + film texture + type | low |
| `swiss-kinetic.md` | sharp, confident, electronic, rap, pop | code: grid, type, colour blocks | none |
| `light-type.md` | dreamy, ambient, r&b, night drive | code: shaders/WebGL light, type as light | none |
| `painted-story.md` | narrative, fantasy, emotive | generated stills from a reference sheet, animated in the engine | medium–high |

If none fits, write a new recipe in the same format into the project (`frames/STYLE-RECIPE.md`) before the spec.
